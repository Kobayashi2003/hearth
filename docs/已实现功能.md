## 九、2.0 重构记录（2026-09-25）

- **删除"继续阅读"展柜**：首页的 Pinned / Continue 两排卡片、Ledger 的 `recent` / `pinned`、偏好 `showShelves`、只为它服务的 `GET /files/entry` 一并删除。进度本身保留（续播、续读与进度条仍依赖它）。1.x 的 Ledger 文件在启动时自动迁移。
- **后端整理**：Ledger 与 Hob 改用共用的 `UserDocuments`；重复的 `abortSignalOf` / `requireUser` 等收进 `lib/request.ts`；`worker-pool.ts` 改名 `worker.ts`；worker 的异常能正确传回父线程；目录遍历的队列从 O(n²) 改为 O(n)；回收站与移动共用跨卷移动逻辑；版本号取自 package.json；Fastify 弃用项与 AJV 联合类型警告清除；注释只保留安全边界与不直观之处。约 7,500 → 6,700 行。
- **前端重写**：全部界面重做（新配色、字体、布局、标志），约 15,800 → 6,800 行自有代码。EPUB 改用新的阅读器组件。旧版的"多个预览并存 / 最小化到坞 / 固定 / 可拖拽大小的预览窗口 / 悬停预览卡片"没有保留（见拟实现功能）。
- **安全修正**：Markdown 以前直接把 `marked` 的输出插进页面，文件里的 HTML/`javascript:` 链接能以当前会话执行；现在原始 HTML 显示为文本，链接与图片地址白名单化。
- **文档**：旧的英文 `docs/`（架构、配置、Everything 设置、ADR）合并进这四份中文文档。
