## 一、总览

Vite 7 + React 19 + TanStack Router / Query + Tailwind CSS 4 + Radix（Dialog、DropdownMenu、Switch）+ lucide 图标，TypeScript。自有代码约 6,800 行；另有原样复制进来的 EPUB 阅读器约 34,000 行（`src/vendor/epub-reader/`）。

产物是纯静态文件，由 Caddy 直接吐出，没有前端服务器进程。几条贯穿全局的约定：

- **浏览状态全在 URL 里。** 当前目录、排序、搜索词、搜索范围、类型过滤都是 hash 路由的 query（`#/?path=…&sort=…&q=…`）。后退 / 前进像文件管理器一样工作，任何一屏都能收藏或粘贴复现。用 hash 路由是因为应用挂在一个运行时才知道的前缀下（`/hearth/`），不需要服务端重写规则。
- **偏好属于人，不属于浏览器。** 主题、密度、视图等存在服务端（Hob），换设备也一样；本地只存一份镜像，供 `index.html` 里的内联脚本在首帧前设置主题，避免深色用户每次打开先闪一下白。每个浏览器自己的便利（音量、阅读器排版、换行开关）才放 localStorage。
- **进度属于人。** 视频/音频时间、漫画页码、文本滚动位置、EPUB 阅读会话都写进服务端 Ledger，手机上能接着桌面看。
- **重的东西懒加载。** 每种查看器都是独立 chunk；EPUB 阅读器、代码高亮（shiki 与各语言语法）只有打开对应文件才下载。
- **API 地址固定在根下 `/hearth-api`**（可用 `<meta name="hearth-api-base">` 覆盖），资源用相对地址，所以同一份构建能挂在任意前缀下。

#### EPUB 阅读器的接入

`src/vendor/epub-reader/` 是 `D:\Program\Code\components\src\library\data-display\epub-reader` 的 `core/`、`react/`、`types/` 与 `styles.css`（去掉了只属于演示页的 showcase 样式），**除 `core/extension/model.ts` 一处补了 `override` 关键字以通过本项目更严格的编译选项外未作修改**；它有自己的 lint 规则，Hearth 的 ESLint 忽略该目录。更新时整体重新复制并重新打上这一处改动即可。

`EpubViewer.tsx` 负责把它接到 Hearth：

1. 同时下载书的字节（`/media/raw`）和该用户这本书的阅读会话（`/ledger/session`）。
2. 给阅读器一个同步的 `ReadingSessionStorage`：`load` 返回预先取到的记录；`save` 更新内存并在 1.5 秒防抖后 PUT 回服务端，同时按"第几章 + 章内进度"估算百分比写进 Ledger 进度（列表里的进度条来自这里）；`remove` 删除服务端记录。
3. 会话键就是文件路径，所以重命名/移动时 Ledger 的 `reprefix` 会带着它走。
4. 初始页边距设为 6%（阅读器默认贴边）；已有会话里保存的偏好优先。

阅读器自带目录、搜索、书签/高亮/批注、排版与主题设置、全屏和键盘帮助，Hearth 只在它上方保留一条细的顶栏（文件名、下载、全屏、关闭）。
